> **Planejamento, não laudo de execução.** Todos os resultados estão **NÃO EXECUTADO** até que o código integrado seja testado. Ajustar as instruções à interface real do grupo.

## Preparação

1. Conferir que o `sistema.py` atualizado está no repositório e carrega os arquivos esperados em `dados/`.
2. Executar `python src/sistema.py` a partir da raiz do projeto.
3. Guardar uma cópia dos dados originais; cadastros e atualizações podem alterar contagens ou persistência.
4. Usar `OC013` (categoria vazia) para testar dados inválidos **sem** contá-la como ocorrência válida.

## Como preencher os resultados

Para cada caso, substituir `—` pelo comportamento observado, e `NÃO EXECUTADO` por `APROVADO`, `REPROVADO` ou `BLOQUEADO`. Se um teste falhar, registrar qual entrada foi utilizada e a mensagem ou o erro observado. Se alguma regra for diferente no código, alinhar com o grupo e ajustar o resultado esperado.

**Nota:** os totais T10, T11 e T16 se referem ao CSV original, sem alterações de cadastro ou status. O teste T07 é uma boa prática de qualidade compatível com o relato do grupo, mas não substitui os requisitos mínimos de validação do enunciado.
